1. Executive Summary

VetKind India is a comprehensive web platform for a veterinary nutrition and phytogenic solutions company based in Jaipur, Rajasthan. The platform serves as both a customer-facing product showcase and an internal business management tool.

The application is built on Next.js 16 with React 19, utilizing server-side rendering (SSR) and server components for performance and SEO. It employs a three-portal architecture:

  1. Public Website — Product catalogue, solutions, knowledge base, blog, news & events, research articles, company information, and contact/inquiry forms.
  2. Admin Portal — Full CRUD management for products, species, solutions, knowledge articles, research articles, news & events, blog posts, distributors, inquiries, and user accounts.
  3. Distributor Portal — Dedicated dashboard for authorized distributors to access product resources, brochures, datasheets, pricing, and manage order requests.
Current Status: The platform is in active development. Core features (product management, content modules, admin dashboard, distributor portal) are functional. Authentication is temporarily bypassed for admin/distributor routes during development. Pre-launch items (contact details, Google Maps, CRM integration) remain as placeholders.

4.3 Key Architectural Decisions

  • Server Components First: All pages use React Server Components by default for performance and SEO.
  • Server Actions: All data mutations (CRUD) are handled via Next.js Server Actions, eliminating the need for separate API endpoints.
  • Route Groups: Next.js route groups (admin), (auth), (distributor) enable separate layouts per portal.
  • Shared Root Layout: The public website header and footer wrap all public pages via the root layout.
  • Dual Database Strategy: SQLite for local development; Supabase (PostgreSQL) for production, managed via environment variables.
